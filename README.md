# ALBA MSc Project — Hardware and Firmware Archive

This repository contains the final hardware design files and ESP32 firmware
supporting the ALBA MSc thesis:

**Development of an Integrated Sensing and Control Platform for a Soft Robotic
Bladder Assist System**

## Contents

- `hardware/PCB_V1.0/` — final PCB V1.0 editable project and schematic.
- `firmware/alba-v3/` — final ESP32 firmware and host-side logging scripts.

Closed-loop MATLAB/Simulink control simulations are archived separately in:

[ALBA_Step9_ClosedLoop_v3](https://github.com/Shijia0366/ALBA_Step9_ClosedLoop_v3)

The closed-loop control results reported in the thesis are simulation-based.
